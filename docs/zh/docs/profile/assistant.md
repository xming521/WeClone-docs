# 接入 AI 助理

Claude Code、Codex 等支持 MCP 的助手可以读取你的人生画像，作为长期记忆使用。能读哪些板块、读到哪个隐私级别，由你在网页上设定。

## 准备

1. 完成[绘制人生画像](./build-profile.md)，用 `weclone-cli server` 打开网页。
2. 在「板块总结」页确认要提供的[总结](./summary.md)。只有确认过的总结会提供给助手。

## 设置提供的内容

在「助手接入」页（`#/assistant`）选择隐私级别和板块：

| 隐私级别 | 助手能读到的条目 |
|---|---|
| 全部 | 所有条目，包括私密和敏感的 |
| 普通 | 公开和普通条目 |
| 公开 | 只有公开条目 |

- 板块默认全部提供，之后新出现的板块也提供。勾掉的板块，总结和条目都不给助手。只提供部分板块时，之后新出现或改名的板块不提供。
- 修改级别和板块后，从助手的下一次调用起生效，不需要重新配置。
- 这些设置和令牌保存在 `.weclone/` 中，重新绘制画像后仍然有效。

> [!WARNING]
> 选择「全部」时，私密和敏感条目也会交给助手背后的云端模型。

## 生成令牌并配置助手

点击「生成令牌」。令牌只显示这一次，页面上会给出对应助手的配置命令，在运行助手的机器上执行，之后新开的会话就能调用 WeClone。

Claude Code：

```bash
claude mcp add -s user --transport http weclone http://127.0.0.1:5175/mcp --header "Authorization: Bearer <令牌>"
```

Codex：在 `~/.codex/config.toml` 中加入

```toml
[mcp_servers.weclone]
url = "http://127.0.0.1:5175/mcp"
http_headers = { Authorization = "Bearer <令牌>" }
```

其他支持 MCP 的助手：地址填 `http://127.0.0.1:5175/mcp`，请求头加 `Authorization: Bearer <令牌>`。

所有助手共用这一个令牌。「重新生成」后旧令牌立即失效，已经配置好的助手都要用新的命令再配置一次。「停用」后所有助手都读不到 WeClone。

## 助手使用的工具

| 工具 | 返回 |
|---|---|
| `weclone_profile` | 所选级别和板块下确认过的板块总结，每段前标有板块编号 |
| `weclone_search` | 按关键词或板块编号查找画像条目，最多返回 50 条。包括待审核的条目，不包括不采纳的条目 |

WeClone 会提示助手：画像可能有误或已经过时，查到的内容只作参考，涉及重要决定时先跟你确认。

## 保持服务运行

助手使用期间要保持 `weclone-cli server` 运行。

- 加密模式下，助手只能在你允许的时间里读取。在「允许助手读取」中选择 1 小时、8 小时、24 小时或 7 天。允许期间服务在内存中保留一份密钥，到时间或服务重启后清除，需要重新打开。也可以「立即关闭」。
- 明文模式下，令牌有效时助手随时可以读取。

每次调用都会记录在审核数据库中，包括发起调用的客户端、工具、参数和返回内容。

## 不支持 MCP 的助理

在「板块总结」页复制导出文本，粘贴到助理的「关于我」、自定义指令或 USER.md，见[板块总结](./summary.md#复制给不支持-mcp-的助理)。
