# 语言风格

语言风格分析只读取你本人发出的消息，覆盖十大类、179 项风格特征。结果在网页的「语言风格」页（`#/style`）查看，之后也将用于驱动 Agent 分身。

## 运行

先安装[语言风格依赖](../deploy/environment.md#语言风格依赖)，然后选择做分身：

```bash
weclone-cli build-profile --purpose clone
```

风格抽取是 `build-profile` 的最后一步，结果写入结果目录的 `style/`，网页的风格页读取同一次结果。

## 分析的内容

| 类别 | 例如 |
|---|---|
| 词汇选择 | 高频词、语气词、口头禅、网络流行语、缩写 |
| 语法结构与句式 | 句长、词性分布、强度副词 |
| 书写与副语言形式 | 标点使用、连续标点、完全不用标点 |
| 整体语体 | 书面语与网络聊天语、互联网化程度 |
| 语气、立场与交际基调 | 确定性、礼貌与客套、拒绝时的缓冲 |
| 情绪表达 | 情感词比例、情绪强度、吐槽倾向 |
| 修辞手法 | 比喻、夸张、反讽、排比 |
| 篇章组织与信息展开 | 展开与补充、因果、对比 |
| 对话互动与消息节奏 | 连发、追问、话题的延展与结束方式 |
| 情境比较层 | 私聊与工作群、家人与朋友、白天与深夜 |

一部分特征由本地统计得出，基于全部消息。另一部分由模型在抽样的对话中判断，页面上会注明依据。

## 风格页

风格页把最明显的特点按打字习惯、用词、情绪表达、说话方式分组，用泡泡大小表示出现的频率，只列出足够常见的特点。点击一个特点可以看到：

- 出现频率，例如「多数时候」「常常」「有时」「偶尔」
- 常见写法
- 跟不同的人聊天时的差别，各人的数字已按消息长短校正

## 单独运行

已经有结果目录时，可以只重新抽取风格：

```bash
weclone-cli distill-style --input-dir <结果目录>/people
```

| 参数 | 说明 |
|---|---|
| `--input-dir` | 聊天快照目录或单个文件 |
| `--output-dir` | 新的输出目录，默认在 `dataset/res_csv/agent/distill/style/` 下新建 |
| `--ltp-model` | LTP 模型目录，默认 `models/LTPbase` |
| `--window-days` | 只分析最新一条记录之前多少天内的聊天，默认 365，`0` 表示全部 |
| `--llm-samples` | 交给模型判断的对话段数量，默认 2000，`0` 表示全部 |
| `--no-llm` | 只运行本地统计，不调用模型 |
| `--limit` | 只取前 N 个对话段，用于试跑 |
