# 板块总结

板块总结为每个板块写一段话，作为给个人助理的背景资料。确认过的总结会进入导出文本，也会通过 [MCP](./assistant.md) 提供给助手。

## 三个级别

在「板块总结」页（`#/summary`）选择隐私度上限：

| 级别 | 依据的条目 | 生成时机 |
|---|---|---|
| 全部 | 所有还成立的条目，包括私密和敏感的 | `build-profile` 最后一步自动生成 |
| 普通 | 隐私度为公开或普通的身份、目标、条件和偏好 | 在页面上点击生成 |
| 公开 | 隐私度为公开的身份、目标、条件和偏好 | 在页面上点击生成 |

普通和公开两级的总结较短，不使用计划承诺和已过时的信息，因为这些内容变化快，不适合常驻在助手的上下文中。

## 生成与确认

- 「生成 N 个板块」为每个板块调用一次模型，通常一两分钟，模型繁忙时会更久。生成在后台进行，可以先离开页面。没有生成成功的板块，下次生成时只补这些板块。
- 每段总结可以「确认」「编辑」（「保存并确认」）、「不导出」，确认后也可以「撤回确认」。「全部确认」一次确认所有待确认的总结。
- 总结依据的画像一旦改动，这段总结就停止导出，状态变为「需重新生成」，重新生成并确认后才会再次提供。
- 一个板块没有可用条目时（条目都高于所选隐私度，或者都是计划承诺和已过时的信息），不会生成总结。

## 复制给不支持 MCP 的助理

页面下方的「导出文本」汇总所选级别下确认过的总结，可以粘贴到个人助理的「关于我」、自定义指令或 USER.md。

- 「每个板块附原始条目」可以选择不附，或附 3、5、10 条。
- 选择「全部」级别时，导出文本含私密和敏感的内容，复制前会再次确认。

> [!WARNING]
> 贴出去的内容收不回来，复制前请再看一遍。只想给助理少一些内容时，可以切到普通或公开级别另外生成一份。
