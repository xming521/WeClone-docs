# 网页审核

## 打开网页

```bash
weclone-cli server                    # 打开最新一次结果
weclone-cli server --run <结果目录>   # 打开指定的一次结果
```

在浏览器中打开 http://127.0.0.1:5175 。服务启动时选择 `dataset/res_csv/agent/profile_runs/` 下最新一次完整的结果，未完成的结果会被跳过。

- 首次打开时设置共用密码，之后用它登录，见[数据安全](../security/data-security.md#密码)。登录有效期为 2 小时，请在自己的设备上使用。
- 服务默认只监听本机。`--host` 和 `--port` 可以修改地址和端口，端口也可以用环境变量 `API_PORT` 设置。
- 网页按浏览器语言显示中文或英文，可以用顶栏的「中/EN」切换。

| 页面 | 用途 |
|---|---|
| 人生画像（`#/`） | 按板块和主题浏览画像，逐条审核 |
| 说话风格（`#/style`） | 查看 `--purpose clone` 抽取的[说话风格](./style.md) |
| 板块总结（`#/summary`） | 生成和确认各板块的[总结](./summary.md) |
| 助手接入（`#/assistant`） | 设置助手能读取的内容，生成令牌，见[接入 AI 助理](./assistant.md) |
| 机器人接入（`#/bots`） | 生成聊天机器人调用分身的令牌，见[启动服务与令牌](../chatbot/bot-token.md) |

## 浏览画像

画像以图谱展示：悬停点亮归属路径，点击展开并聚焦，再点一次收起，拖动节点可以牵动图谱。顶部的搜索框可以查找主题、属性或内容。

左栏可以在「按维度」和「按板块」之间切换分组方式，浏览器会记住你的选择。按板块浏览时，同一主题下不同维度的属性合并显示，每张审核卡片会标出所属维度。

右栏分为两个标签页：

- 「总览」显示条目数量、审核进度、隐私度分布和下一级的导航。
- 「画像审核」列出当前范围内的条目，可以按审核状态筛选。

## 审核条目

每条画像有三种状态：待审核、已采纳、未采纳。

- **采纳**或**不采纳**：逐条处理，或先「全选」再批量处理。选中的条目中有尚未显示在列表里的，会先请你确认数量。
- **编辑**：修改属性名称、归属位置和内容。「保存」后条目移回待审核，「保存并采纳」直接采纳。不做修改直接保存时，状态不变。
- **移回待审核**：撤销已经做出的决定。
- **新增画像**：手动添加条目，标记为「手动添加」，不带评分。
- **查看修改历史**：每条画像的审核、新增和编辑记录。

已采纳的条目构成分身画像。不采纳的条目仍然保留，可以随时恢复。

## 隐私度与来源

每条画像和每条证据都标有隐私度：

| 隐私度 | 含义 |
|---|---|
| 公开 | 对陌生人也会说 |
| 普通 | 熟人之间会聊 |
| 私密 | 只对亲近的人说 |
| 敏感 | 只留在原来的聊天里 |

在「画像审核」中可以按隐私度筛选，不选时显示全部。卡片上还会显示可信度、重要度（来源评分的平均值，编辑后不会重新评分）和检索标签。

点击「查看原文」，在审核栏旁边打开抽取这条画像时使用的聊天片段。原文从本次结果的抽取文件中读取，删除或修改这些文件后无法查看。

## 导出

「导出当前视图」下载一个 JSON 文件，包含当前审核状态筛选下的画像层级和关联来源，每条画像带有审核状态。导出范围不受图谱中选中节点的影响。

## 审核记录

审核记录保存在该次结果的 `profile_hierarchy/profile_review.sqlite3`（加密模式下为 `.sqlite3.enc`），只属于这一次结果。数据库首次创建后，之后的启动都读取它，不再重新导入画像文件。备份时请一并保留。
