# 数据安全

## 哪些内容会离开本机

| 功能 | 发送的内容 | 发送给谁 |
|---|---|---|
| 绘制人生画像 | 抽取、整理和总结时的聊天内容与画像条目 | 你配置的模型服务（Codex 或 API）。开始前会提示并请你确认，已经抽取过的内容读取本地缓存，不会再次发送 |
| 接入 AI 助理 | 助手读取到的总结和条目 | 助手背后的模型服务。选择「全部」级别时，私密和敏感条目也包括在内 |
| 复制导出文本 | 你复制的总结和条目 | 你粘贴到的助理 |
| 微调分身 | 训练和推理都在本机运行 | 开启在线 LLM 数据清洗（`online_llm_clear`）或图片转文字（`vision_api`）时，相应内容发送给配置的 API |

## 存储模式

在 `settings.jsonc` 中设置：

```json
"security_args": {
    "storage_mode": "encrypted"
}
```

| 配置项 | 说明 |
|---|---|
| `storage_mode` | `encrypted`：模板默认值，聊天数据及其衍生产物加密保存，文件以 `.enc` 结尾。`plaintext`：明文保存。未设置 `security_args` 的旧配置使用明文 |
| `state_dir` | 保存密钥和令牌记录的目录，默认 `.weclone` |
| `runtime_dir` | 加密模式下，训练、推理等需要明文文件的步骤把解密后的临时文件放在这里，任务结束后删除。默认使用系统临时目录 |

加密的内容包括聊天快照、画像、审核记录、训练数据和微调模型。加密模式暂不支持分布式训练。

存储模式在首次初始化后固定。切换模式需要在新的输出目录中从原始聊天重新生成全部数据，加密模式也不能加载旧的明文模型。原始聊天和手动导出的明文文件不受 WeClone 管理，请自行保管。

## 密码

网页登录和加密数据共用一个密码。首次打开网页或运行任务时设置，也可以提前执行 `weclone-cli security-init`，按 `settings.jsonc` 固定存储模式并设置密码。密码不会以明文保存，也不能写进配置文件。

```bash
weclone-cli security-init                                        # 初始化存储模式并设置密码
weclone-cli security-change-password                             # 使用旧密码修改，保留数据
weclone-cli server-reset-password                                # 忘记密码时重置
weclone-cli decrypt --input <加密文件> --output <新的明文文件>  # 导出明文
```

- 修改密码后，已有数据保留，旧的网页会话失效。
- 忘记密码无法恢复旧密文。重置后旧文件保留，但需要在新的输出目录中从原始聊天重新生成数据，机器人令牌也要重新生成。
- 网页登录有效期为 2 小时。

## 密钥与令牌

`.weclone/` 目录保存用密码加密的数据密钥（`manifest.json`），以及助手和机器人的令牌记录（`assistant.sqlite3`、`bots.sqlite3`）。读取加密数据必须用到这个目录，请保留并备份。

- 两种令牌都只保存哈希，只在生成时显示一次，丢失后重新生成即可。
- 助手令牌在加密模式下只在你允许的时间内可用，见[接入 AI 助理](../profile/assistant.md#保持服务运行)。
- 机器人令牌在加密模式下会和数据密钥一起保存：数据密钥用令牌加密后存进 `bots.sqlite3`，机器人调用时凭令牌解开，不需要有人登录。令牌和这个文件放在一起就能解密全部数据，要像密码一样保管。修改密码后它仍然有效，重置密码后需要重新生成。
- `/v1` 和 `/mcp` 拒绝带 `Origin` 请求头的请求，网页即使拿到令牌也无法调用。

## 服务地址

`weclone-cli server` 默认只监听 127.0.0.1。为 Linux 上 Docker 中的机器人平台改用 `--host 172.17.0.1` 时，同一网络中的其他程序也能访问这个端口，请只在可信的机器上这样做，不建议直接暴露到公网。

## 请求日志

WeClone 调用模型服务的请求记录在 `logs/llm_audit/` 中。加密模式只记录元数据，明文模式会记录完整的请求和回复。助手通过 MCP 的每次调用记录在审核数据库中。
